# Guayaquil en Bici

Sitio web oficial de **Guayaquil en Bici**, un colectivo ciudadano dedicado a promover el ciclismo urbano como medio de transporte sostenible, seguro y accesible en Guayaquil, Ecuador.

## Sobre el Colectivo

Guayaquil en Bici (GEB) es una organización ciudadana comprometida con diversos proyectos que incrementan la cultura de la bicicleta, fomentando una sociedad con mayor conciencia de convivencia y respeto en la ciudad.

### Nuestra Misión

- **Incentivar el uso de la bicicleta** en Guayaquil en todas sus modalidades, principalmente como medio de transporte
- **Ser un referente** en temas de ciclismo urbano y movilidad sostenible
- **Generar información relevante** para fomentar una ciudad con mayor convivencia y respeto
- **Trabajar por políticas públicas** que promuevan el derecho a circular en bicicleta

### Nuestras Actividades

- **Masa Crítica** - Rodadas mensuales por las calles de Guayaquil
- **Día Mundial Sin Auto** - Evento anual promoviendo medios de transporte alternativos
- **Alleycat** - Competencias urbanas en bicicleta
- **Semana de la Movilidad** - Actividades educativas y de concientización
- **Talleres y Charlas** - Educación sobre ciclismo urbano seguro

## Sobre el Sitio Web

Este sitio fue migrado desde Drupal 7 a una plataforma moderna construida con:
- **Astro 5** - Framework de desarrollo web estático
- **TinaCMS** - Sistema de gestión de contenidos
- **Tailwind CSS** - Framework de estilos
- Desplegado en **Netlify**

El sitio incluye:
- Blog con artículos sobre ciclismo urbano y movilidad sostenible
- Información sobre eventos y actividades
- Recursos para ciclistas (talleres, tiendas, clubes)
- Formulario de contacto

## Desarrollo

```bash
# Instalar dependencias
pnpm install

# Servidor de desarrollo (con TinaCMS admin en /admin)
pnpm run dev

# Servidor de desarrollo (sin TinaCMS, más rápido)
pnpm run dev:astro

# Construir para producción
pnpm run build

# Previsualizar build
pnpm run preview
```

**Requisitos:**
- Node.js 20.18.1
- pnpm (gestor de paquetes)
